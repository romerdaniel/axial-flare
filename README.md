# Axial Flare - AI Drilling Co-Pilot

Prescriptive ML model that recommends optimal drilling parameters (WOB, RPM)
to maximize Rate of Penetration (ROP) while keeping Mechanical Specific Energy
(MSE) within safe operational windows.

**Dataset:** Equinor Volve Field - Well F-9_A (North Sea, Norway)
**Model:** Gradient Boosting Regressor (R2 = 0.876)
**Built with:** Python, Scikit-learn, Streamlit, Plotly

Capstone Project - ML and AI Postgraduate Program, UT Austin
